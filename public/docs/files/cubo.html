neo-cube — carpeta del motor (privado)

El Cubo de Neo: motor en C++ de scenarys. Repositorio privado: https://github.com/NeoRetroo38/neos-cube No metas aquí código del motor ni el token. El motor no tiene interfaz de producto; solo hay un banco de pruebas.

Cómo encaja (sketch)

app móvil / web (choisys)
   -> API (Express: validación, cuentas, sesiones)
      -> localhost:8765  neo-cube-service (C++, solo loopback, con token)
         -> Cubo de Neo (3 fases, cubo 3x3x3)

La app nunca llama al puerto 8765 ni conoce el token. Del motor solo sale measurements: [{ phase, row, column }].

Interfaces que sí existen

  • Consola (neo-cube.exe, experimental/console.cpp) y GUI de Windows (experimental/gui.cpp): banco de pruebas local.
  • Servicio HTTP local (neo-cube-service): lo usa la API. Windows con build.ps1 y run.ps1; macOS y Linux con make y run.sh.

Futuras implementaciones
