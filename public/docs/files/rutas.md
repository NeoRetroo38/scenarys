# Una dirección para todo

scenarys vive en la raíz de neowebdevsolutions.com. Cada app del ecosistema se abre en una ruta de esa misma dirección.

| Dirección | Qué es |
| --- | --- |
| neowebdevsolutions.com | scenarys: la compañía y sus productos |
| neowebdevsolutions.com/choisys | choisys en el navegador, sin instalar nada |
| neowebdevsolutions.com/docs | esta documentación |
| neowebdevsolutions.com/downloads | lo que se puede descargar, con tamaño y SHA-256 |

## Qué significa para quien la usa

- **Una sola dirección.** Las próximas apps se añadirán como `neowebdevsolutions.com/<app>`.
- **Enlaces directos.** Cada pantalla de una app tiene su enlace, por ejemplo `/choisys/register`, y se puede guardar o compartir.
- **Rutas fijas.** La ruta de una app es solo suya: ninguna página de la web la reutiliza.

## Qué no cambia

- **El motor.** El motor del Cubo de Neo no se expone en internet: se ejecuta en local y solo lo consulta la API de choisys.
