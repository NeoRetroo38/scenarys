Cómo se conecta el motor

Del toque en la app al resultado: cinco pasos, sin abrir la caja del Cubo.

  1. 1

    La app

    Móvil o web.

    • La persona responde
    • Envía a la API
  2. 2

    La API

    Express.

    • Valida entradas
    • Cuentas y sesiones
    • DTO seguros
  3. 3

    Servicio local C++

    Solo en la misma máquina.

    • localhost:8765
    • Solo loopback IPv4
    • Token Bearer
    • Peticiones acotadas
    • Logs mínimos, sin cuerpos
  4. 4

    El Cubo de Neo

    El cálculo.

    • 3 fases
    • Cubo 3×3×3
    • Resultado determinista
  5. 5

    Respuesta pública

    Solo lo necesario.

    • Solo measurements
    • [{phase,row,column}]
    • Posiciones base 1

  • Matrices
  • Pesos
  • Fórmulas
  • Estados intermedios
  • Trazas
