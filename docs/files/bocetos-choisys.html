4. Cómo se amplía la interfaz sin romperla

Principios
1. Una acción por pantalla. Si una pantalla necesita dos, se divide en dos.
2. Blanco, negro y fade; el color solo aparece en la vista del cubo (verde neón y rojo).
3. La app dibuja lo que el servidor le entrega; nunca calcula resultados del Cubo.
4. Toda pantalla nueva lleva etiquetas accesibles y funciona sin sonido.
5. Una pantalla nueva se propone aquí como boceto, se decide en un PR de docs/decisions y solo entonces se implementa.
